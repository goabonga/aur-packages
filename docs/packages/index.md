| [`yate-bts`](yate-bts.md) | [AUR](https://aur.archlinux.org/packages/yate-bts) | YateBTS - an open source GSM base station, running on the Yate engine |

The per-package pages are generated from each `packages/<name>/README.md`
by `scripts/gen-package-docs.py`; edit the README, not the generated
page.

## Installing

```bash
yay -S <name>
```

Or build from this repository:

```bash
cd packages/<name> && makepkg -si
```
